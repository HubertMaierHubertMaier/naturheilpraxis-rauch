# Uebergabe an Klaus - Sync-Ziel

Datum: 2026-07-11

## Uebergeordnetes Ziel

Das letztendliche Ziel in diesem Projekt ist, dass die Kommunikation, Programmierung, Speicherung und alle dafuer noetigen Stufen zwischen OpenCode, GitHub und Lovable synchron und ohne vermeidbare Fehler zusammenlaufen.

## Gemeinte Ebenen

1. lokaler Arbeitsstand
2. GitHub `main`
3. Lovable-Projektstand / Preview
4. oeffentlicher Lovable-Publish-Stand
5. relevante Speicher-, Gating-, Konfigurations- und Backend-Zustaende

## Praktische Arbeitsregel

Ein Block ist erst dann wirklich fertig, wenn diese Ebenen nicht nur einzeln funktionieren, sondern auch denselben gemeinten Stand abbilden.

## Wichtige Konsequenz

Wenn etwas lokal oder auf GitHub richtig aussieht, Lovable aber abweicht, ist die Aufgabe nicht abgeschlossen. Dann muss die Synchronitaet der Staende vor weiterer Arbeit wiederhergestellt werden.
